# 时序与安全

## 固定周期

| 周期内时刻 | 动作 |
|---|---|
| 0 µs | 核验上周期许可、租约及算法结果，锁存 PWM |
| 15000 µs | 强制 PWM 低，放电 |
| 15100 µs | 关闭加热请求 |
| 15200 µs | 接通测量路径 |
| 16800 µs | 通知任务启动四路 ADC |
| 17100 µs | ADC 启动完成截止 |
| 19050 µs | ISR 强制关闭测量路径 |
| 19350 µs | 汇总帧与后台安全样本 |
| 19900 µs | PWM 低时预充电 |
| 20000 µs | 下周期 |

ADC Turbo 660 SPS、增益 4、外部参考、IDAC 1.5 mA；2 MHz SPI 单句柄长期独占，四路软件片选。DRDY 下降沿独立锁存，最早接收时间为启动后 1200 µs；读取前保留 100 µs 截止余量。比例换算参数来自构建配置；目前没有温度换算及运行时校准写入。

## 输出保护

GPIO 互锁、预充电、PWM 和测量截止均属于实时组件。迟到超过配置阈值或闹钟重设越过阶段裕量时关闭请求并跳到未来绝对边界。ISR 不做 SPI、日志、分配、阻塞或 Flash 写入；DRAM 数据、IRAM 调用链及 `heater_board/linker.lf` 映射必须保留。

每个通道只有在上一完整周期有效、自举准备完成、运行有效且无 PWM 锁存故障时才允许输出。原始码非正、饱和及电阻越界禁止该通道下一周期加热；时序/PWM 故障使整帧无效。STOP 或算法故障截断当前测量路径时，该帧也不再获得通道许可。PWM 操作失败锁定加热直到重启。

STOP 不读取时钟，不等待应用门闩。它先关断、取消运行、更新记录接收代次；任务中的 STOP 再经过记录锁屏障才回复确认。USB 断开回调只快速关断，不等待历史锁。5 秒租约在周期边界检查；数据读取、算法计算及 WS 查看不会续约。

## Flash 事务

应用操作先取得可转交 OTA worker 的二值门闩；Flash 事务再取得同任务持有的 mutex。发起维护后禁止正常命令，关闭输出，控制任务停止 GPTimer 并等待当前 ADC 操作结束，只有确认成功才能写入。

事务覆盖 NVS、镜像写入、镜像校验及启动分区选择，结束前不得恢复采样。失败保持暂停或维护禁止状态；恢复只开启空闲安全采样，必须显式 START/RSTART 才加热。暂停超时不能授权写 Flash，Flash mutex 只能由原任务释放。

启动阶段首次凭据写入是唯一例外：它在控制及采样启动前完成。启动确认仍通过完整暂停事务。启动恢复模式只在能确认板级输出关闭时开放网络升级。

## 数据含义

`cycle_start_us` 是周期起点，不是 ADC 实际采样时刻；四路转换命令略有先后。`measurement_age_us` 是最近安全帧发布后的单调时间，维护期间会增长。PWM 为周期起点的锁存值；STOP 或异常可能截断加热。faults 与 blocked_mask 用于解释这种差异，不能用占空比积分声称实际能耗。
