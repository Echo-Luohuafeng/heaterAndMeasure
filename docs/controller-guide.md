# 恒电阻算法开发

## 接口与注册

算法继承 `components/heater_controller/include/controller.hpp` 中的 `heater::Controller`，实现 `Configure/Reset/Step`，需要执行器反馈时实现 `OnApplied`。每个算法使用独立源文件；`controllers.cpp` 注册稳定 ID、名称、版本、参数描述、静态对象工厂和校验函数。

算法只依赖 `heater_domain` 的值类型，可独立主机仿真。配置、重置及计算由 Core 0 的工作任务执行；运行中禁止内存分配、阻塞、GPIO/SPI、租约续约或 NVS/Flash。四路共用实验生命周期，输入和输出仍包含四路，以支持未来的耦合算法。

参数用固定 32 个 float 存储；描述表指定名字、偏移、数量、范围及默认值，最多 16 个命名参数。HTTP 和网页从注册表获取描述；新增算法不需要专用路由。

## 配置与执行

空闲时配置；HTTP 返回 `config_id` 和 `state=preparing`。客户端等待同一配置的 ready，然后发送 `RSTART <config_id>`。裸 RSTART 保留兼容，选择当前配置。STOP 保留配置；再次 RSTART 重置算法历史。手动 SET/START 切换到手动模式；恒电阻运行时拒绝手动切换。

第 k 帧结果应用于第 k+2 周期。正常帧在 19.35 ms 发布，到应用边界约有 20.65 ms；这不是完整 40 ms 的计算预算。缺少应到结果会取消运行；旧运行、旧配置及旧代次不能重新锁存。

算法返回浮点候选百分比。通用桥接限制到实验 max_duty，并量化为每计数 0.5 个百分点的 PWM。工作任务及板级驱动校验 0～95% 的接口范围；内核负责通道许可。反馈表示锁存输出及限制信息；故障中途截断不能解释成实测能量。

## 当前 PID

P/I 作用于目标减测量误差，D 作用于测量并经一阶滤波，避免目标阶跃的微分冲击。四路独立状态，Kd=0 可作为 PI。Kp 单位为 %/Ω，Ki 为 %/(Ω·s)，Kd 为 %·s/Ω。条件积分与受限输出回算用于抗饱和，普通量化误差不回算积分。

单路无效时输出零，冻结积分并清除微分历史。时间戳不前进或间隔大于 0.1 秒时拒绝结果。`tolerance_ohm` 用于实验评价，不是控制死区。目标限制为当前有效测量范围，默认 90–180 Ω；只有加热能力，降低目标依赖自然冷却。

示例 `examples/controller-pid.json` 用于功能演示，未针对实际负载完成整定。新增算法须通过主机仿真、失效输入和时间戳测试，再按实验输出配置验证硬件时序、无效帧和栈余量。

维护失败并释放操作门闩后，新的有效配置请求可以恢复已确认暂停的后台安全采样，再准备配置；仍需 RSTART 才开始加热和记录。Flash 事务进行中或暂停未确认时拒绝该操作。
