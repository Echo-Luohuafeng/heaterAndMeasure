加热控制

先填写四路设定，再点击“开始加热”才会加热并记录数据。勾选“加热保持”后每秒续约；取消勾选后停止续约，默认 5 秒后停热并停止记录。页面重开或设备重启不会自动开始。

先停止，再配置目标与参数；开始后自动调节 PWM。只有加热能力，目标较低时自然冷却。误差带用于实验评价。PID 参数单位：Kp 为 %/Ω，Ki 为 %/(Ω·s)，Kd 为 %·s/Ω。

固件升级

选择本工程的应用 .bin。升级会停止加热并暂停测量，成功后重启；失败后可点击“开始加热”恢复控制任务并开始新的加热记录。
